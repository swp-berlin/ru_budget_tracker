| File | Material Icon name | Usage |

| `dashboard.svg` | dashboard | View-switch button label when on the Timeseries page (links back to Treemap) |

| `info.svg` | info | Toolbar button — navigate to the About page |

| `share.svg` | share | Toolbar button — copy shareable link to clipboard |
| `stacked_bar_chart.svg` | stacked_bar_chart | View-switch button label when on the Treemap page (links to Timeseries) |
